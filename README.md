# SISTEMA WEB PARA RECEPCIÓN DE PEDIDOS Y CONTROL DE STOCK
## 1. Objetivo general
Desarrollar un sistema web con funcionalidades de control de stock (Añadir, modificar, eliminar) que sea capaz de recepcionar los pedidos realizados por los clientes mediante vía telefónica o presencial, con el objetivo de mejorar el flujo de ventas y mantener un stock actualizado en cada momento, permitiendo que el restaurante entregue el mejor servicio a sus clientes en cuanto a tiempos de espera y toma de pedidos
